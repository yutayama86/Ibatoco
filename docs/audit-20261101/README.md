### 4. 掲載依頼・広告運用の推奨設計

- 分類は「対価の有無」×「内容を誰が決めるか」の2軸で決める。URL は有料か無料かだけで分けない
- 提供資料に基づく記事は、編集記事として提供元を明示する。対価や依頼者の内容決定があれば PR にする
- PR は最初の受注時に `/pr/` を新設し、編集の推薦枠と news-sitemap から外す
- 先に、ニュース・イベントの区分表示の欠落（方針ページの約束と実装の食い違い）を埋める
- 主力は工数の小さい協賛枠。PR 記事は問い合わせが来たときだけ、本数に上限を付けて受ける
- 仮説価格は既存の公開料金より約75%安く、1時間あたり粗利が低いので、そのままの公開は推奨しない
