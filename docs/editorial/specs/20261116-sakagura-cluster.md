## 検証と次の判断

- 公開条件：4記事の事実確認、`npm run verify`、各記事の`verify:article`、必須CI（build・CodeQL）が成功。通常のPR経路を使用する。
- 公開完了条件：Deploy production成功、`build.json`のcommit一致、4記事・OG画像・一覧・サイトマップ・相互リンクの本番確認。
- 検証対象は上記4URL。公開後7日・28日はGSCでインデックスとクエリ・表示・クリック、GA4で公式リンク送客を確認する。クリックを予約・来訪・売上と扱わない。
- 今回の検索ボリューム、期待PV、期待売上は`unknown`。定量予測を立てず、公開後8〜12週の実測から拡張を判断する。7日だけでSEOの成否を決めない。
- 検索露出と送客が出た蔵・切り口を優先し、反応が乏しければ検索意図とインデックスを見直してから次の3本を判断する。県内全蔵の一括量産はしない。
