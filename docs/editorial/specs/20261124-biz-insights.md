## 最初の5本（構成案）

各記事は「結論 → イバトコの実データ → やり方 → 注意点 → 自分の組織で試す手順 → 現状診断への導線」の順。数字はすべて実測で、測った期間と出典（GA4・Search Console・公式資料）を本文に書く。**因果は断定しない**（「これをしたから伸びた」とは書かず、「やったこと」と「起きた変化」を分けて書く）。

1. **AI検索からの流入が28日で約2倍になった地域メディアが、やっていること**（優先1）
   - 実データ：AI経由のセッション（2026-10-24〜11-20：202、前の28日：103）、AI別の内訳、AIから来たページの種類
   - やっていること：一次情報の確認と出典の明記、組織情報（about・構造化データ）、llms.txt、更新日の管理
2. **AI検索（AIO・LLMO）対策の基本：観光・地域の情報をAIに正しく伝える**（優先1）
   - Google の公式資料（AI機能と検索の関係）を一次情報として引用し、イバトコの実装例を添える
3. **観光の情報発信で、検索から人が来ない3つの理由**（優先2）
   - 実データ：表示はあるのに押されないページ（表示1,000以上・CTR2%未満が22ページ）と、title改善の検証の方法（結果は判定後に追記）
4. **一人とAIで44市町村のメディアを運営する仕組み**（優先3・4）
   - 公式サイトの監視（約60か所）、毎朝の分析、観測期間を決めた改善の判定、事実確認の検査
5. **地域のイベント情報を取りこぼさない仕組み**（優先2・4）
   - 2026-11-23 の取りこぼし点検の実例（冬イベント11件の発見と、監視結果を管理画面へつないだ改善）
