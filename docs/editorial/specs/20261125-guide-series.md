## 他サイトの扱い（最優先）

- 観光いばらき（https://www.ibarakiguide.jp/special/special_ossuume.html）とイバナビ（https://ibanavi.net/）は、**テーマ選びの手がかりにだけ使う**。本文・写真・構成・店の並び・紹介文を写さない、言い換えて再掲しない（AGENTS.md「ニュース公開の安全基準」）。
- イバナビは民間の地域メディア（日宣メディックス運営）で、イバトコの同業。掲載店のリストを流用しない。
- 事実（場所・時期・料金・時間・駐車場・交通）は、施設・自治体・事業者の公式ページで確かめ、`sourceUrls` に公式URLを入れる。観光いばらきは茨城県観光物産協会の公式サイトなので、自治体の情報が見つからない項目に限り出典にしてよい。
- 確認できない数字・時期は書かないか「未確認」と書く。口コミ・ランキング・「人気No.1」は使わない。

## 重ならないようにすること

- 初詣・初日の出・新年イベント・冬のハブは、ChatGPT 側の仕様（20261121-ibaraki-hatsumode-2027 ほか）で準備中。**このシリーズでは扱わない**。
- 既存記事は作り直さず、シリーズのまとめから内部リンクでつなぐ。

## 進め方

1. シリーズ1 → 3 → 2 → 4 の順（時期と手間で決めた）
2. 1記事ずつ下書きPR。`npm run verify:article`・`npm run date:check`・`npm run verify` を通す
3. 新しいイベント・季節記事を足したら `npm run editorial:sync`
4. 公開は既存の Editorial 承認条件の範囲で、オーナーの「#NNNマージ」の後
