# 終了イベントの自動寿命管理と11月回遊への切替

## 目的

2026年10月3日に終了した `rockin'star Carnival 2026` と、10月4日に終了した「かさま新栗まつり」が、保存済みの人気ページ推薦に残り続ける状態を解消する。記事とURLは残し、イベント日付の正本から自動的に推薦対象外となるようにする。

## 実測根拠

- GA4対象期間: 2026-09-27〜2026-10-03（Asia/Tokyo）
- 直近7日Views: 4,511
- かさま新栗まつり: 1,115 Views
- rockin'star Carnival: 200 Views
- GrowthNext: 2,703 view / 115 click / CTR 4.25%

送り先別クリックは取得していないため、期待増分Viewsは `unknown` とし、終了ページへの誤送客を止める回遊保全施策として実施する。

## 変更内容

1. `src/content/news/kasama-shinguri-matsuri-2026.md` に、笠間市公式情報で確認したイベント名、2026年10月2日〜4日、会場、住所、公式URLを `event` として追加する。
2. `data/editorial/popular-pages.json` を直近7日のGA4実測へ更新する。
3. 終了済み2ページを人気推薦在庫から除外し、開催中または恒久利用できる上位ページ8件へ置き換える。
4. Growth/Revenue管理ファイルを同じ観測期間へ更新する。

## 変更しない箇所

- 既存URL、canonical、title、description、H1、本文
- TOPページのレイアウト、カードCSS、画像
- GrowthNextコンポーネントのUI・計測仕様
- 公式発表のない紅葉見頃、交通規制、駐車場、シャトルバス情報

## 受入条件

- `npm run verify` とCIが成功する。
- かさま新栗まつりが2026年10月5日以降 `ended` と判定される。
- 終了済み2ページがTOP人気枠・GrowthNextの推薦先に出ない。
- 両記事のURLは200で維持される。
- 大洗あんこう祭、笠間菊まつり、筑波山交通など、現在行動可能なページが推薦在庫に残る。

## KPI

- 7日後（2026-10-12）: 終了ページの推薦露出0、GrowthNext CTR 2%以上、Views/sessionが急落していないこと。
- 28日後（2026-11-02）: GrowthNextの累積CTR、Views/session、11月重点ページへの遷移を確認する。

## 継続・中止条件

- 継続: 終了ページの推薦露出が0で、GrowthNext CTR 2%以上。
- 修正: 終了ページが再表示される、または日付未登録ニュースが同様に残る。
- ロールバック: 有効なページまで推薦不能になるなど、日付判定の明確な回帰が確認された場合のみ。
