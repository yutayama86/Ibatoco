# イバトコ：地域事業者セルフサービス掲載・収益検証仕様（2026-10-11）

## 目的
受託制作やSNS運用を主収益にせず、地域メディア自体の継続収益を検証する。11月100,000 GA4 Viewsの獲得を妨げない。既存の「予約できるイバトコ」MVP（10/11〜10/17観測）には触れない。

## 最小商品仮説（未販売・未承認）
- **無料の基本掲載**：店名、所在地、公式URL、営業時間等、一次情報で確認できる項目。掲載可否・編集判断はイバトコ側が保持する。
- **有料の拡張掲載候補**：事業者自身が確認・更新できる追加情報、予約/問い合わせ先、更新日表示、閲覧・送客レポート。実装・販売価格・契約条件はオーナー承認後に確定する。
- **スポンサー候補**：特集内の明示的な「PR/協賛」枠。編集記事の順位・評価・推薦は販売しない。
- 自社予約/決済、事業者ログイン、メール配信、個人情報の新規収集、追加有料サービスは現時点で作らない。

## 実行順序とゲート
1. **既存在庫監査**：現在の店舗・施設データ構造、編集導線、掲載申請/問い合わせの既存有無を調査。重複機能を作らない。
2. **需要証拠**：既存の事業者向けCTAの表示・クリック、掲載希望の実問い合わせ、読者側の施設詳細閲覧・送客を同一期間で把握する。GA4欠測・未取得をゼロとみなさない。
3. **手動βの承認判断**：最大10事業者に限定し、更新頻度・問い合わせ負荷・価値提供を測る。無断で営業・課金・契約しない。
4. **採算ゲート**：売上（発生・確定・入金を区別）－決済手数料－更新/サポート等の変動費で貢献利益を確認。月額売上だけで成功としない。
5. **セルフサービス化**：継続利用・支払意思・データ更新負荷が確認できてから自動化。会員管理・決済・個人情報の扱いは別途設計/承認。

## 判断用メトリクス
| 区分 | 指標 | 注意 |
|---|---|---|
| 読者需要 | 店舗・施設詳細の閲覧、公式/予約先クリック | 公式クリックは有料送客ではない |
| 事業者需要 | 掲載問い合わせ、実際の掲載意思、継続意思 | フォーム送信を契約と数えない |
| 継続収益 | 有料契約数、確定月額売上、解約、回収 | 未承認の価格を公開しない |
| 採算 | 事業者あたり月次更新工数、サポート工数、変動費、貢献利益 | 一人運営で再現できるか確認 |
| 品質 | 情報の更新日、誤情報、PR表示、編集独立性 | 有料掲載と編集推薦を混同しない |
