- SEO title: 茨城のイベント 今日・今週末【M月D日更新】開催中の一覧｜イバトコ（日付は JST のビルド日を `src/lib/date-only.js` で生成）

- 冒頭1行: 今日（M月D日）開催中のイベントは◯件。（件数は既存の「開催中」「今日」区分から算出。取得できない場合は件数を出さない）

## 実装指定

- 別URL `/events/this-weekend/` は作らない
- 既存の canonical・構造化データ・セクション構成は維持
