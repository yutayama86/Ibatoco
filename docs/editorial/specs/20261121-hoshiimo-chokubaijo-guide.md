# 干し芋の直売所ガイド

**ポイント**
- 干し芋は茨城県が全国シェアのトップ。その大部分を**ひたちなか市・東海村・那珂市**が作っています
- 主な出荷時期は**11月〜3月中旬**。冬の海風で干すので、まさに今が旬です
- 直売所なら、訳ありの品や、店にしかない品種に出会えることも

## なぜこの地域なのか
火山灰からできた水はけの良い土、寒暖差、ミネラルを含んだ潮風、そして冬に晴れの日が多いこと。この条件が、さつまいもを育てることにも、干すことにも向いています。冬に軒先でさつまいもを干す風景は、この地域の風物詩です。

## 平干し・丸干し・角切り(せっこう)の違い
| 種類 | 特徴 | おすすめ |
|---|---|---|
| 平干し | 薄く切って干す、一番一般的な形 | 初めての人、おみやげ |
| 丸干し | 小さめの芋を丸ごと干す。ねっとり濃厚 | 食べごたえ重視 |
| 角切り・一口(せっこう) | 切れ端や小さいもの。お得なことが多い | 自宅用 |

## 品種で選ぶ
- **紅はるか**:甘くてねっとり。今の主流
- **玉豊(たまゆたか)**:昔ながらの定番。甘さ控えめで、もっちり
