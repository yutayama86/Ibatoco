## 2. 制作方針

- 器は `src/content/events/`（`articleType` が guide / gourmet / event / opening / roundup / tourism）。ニュース解説（/news/）には入れない。
- 取材記事は作らない。公式情報を、行く前の判断に役立つ形に整理する。
- 既存記事と検索意図が重なる候補は新規にせず、「既存の更新」に回す。
- 25本前後を1つのDraft PRにまとめる。マージ・本番公開はオーナー承認後。
