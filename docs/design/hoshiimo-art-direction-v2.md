# 干し芋図鑑｜アートディレクション・公開判定 v2

## 目的
イベントLPや量産型カードUIではなく、「茨城の風土を読む食のデジタルマガジン」として設計する。品種情報の正確さと回遊性を維持しながら、写真とタイポグラフィを主役にする。

## ビジュアル原則
- 生成り #F5F0E8／濃紺 #173C59／蜜色 #B98058。アクセント色は限定的に使用。
- 日本語見出しは明朝系、本文は可読性重視のゴシック系。小さな英字ラベルの多用を避ける。
- 写真・素材が無い箇所を装飾的なグラデーションや過剰なカードで埋めない。
- 品種の色・甘さ・食感を断定的に比較しない。加工・保存条件による差を明示。
- ファーストビューは「短いメッセージ → ビジュアル → 次の行動」の視線設計。PCとモバイルで別途確認。

## 写真ディレクション（公開前の課題）
1. 平干しの断面・透明感がわかる寄り写真（ヒーロー候補）
2. べにはるか／玉豊／いずみ等の品種比較。同一条件・同一光源で撮影し、実物と表示品種の対応を確認
3. 干し場・畑・加工風景の産地写真。撮影者・権利・場所・撮影日を管理
4. 写真には適切な代替テキスト、幅高さ、圧縮、遅延読み込みを設定

※権利未確認のSNS・EC画像は流用しない。写真の代わりに生成画像を置く場合は「イメージ」であることを明記し、品種固有の実物写真として扱わない。
