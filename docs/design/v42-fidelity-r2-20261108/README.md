# イバトコ v42｜デザイン修正・Claude実装引き継ぎ

2026年11月8日。公開済みのv42について、「提出版と見た目が違う箇所」と「旧レイアウトのままの箇所」を修正するためのデザイン資料です。比較の基点は main `641637bf23963c30f27060a422b541baeec28d24`。本番コードや公開設定はこの資料では変更していません。

## 開く

ZIPを展開して **index.html** を開いてください。左の42種類からページを選び、320・375・390・768・1024・1440pxを切り替えられます。「左右で比較」を切ると修正案だけを大きく見られます。

- 左：提出版v42。原本のHTML・CSS・画像は変更していません。
- 右：実装する見た目の修正・補完デザイン。現在のH1を保つ置き方、掲載0件の画面、本文が多いページへの展開を含みます。
- 上の状態切り替え：花の見頃0件・書き手0人、英語・韓国語・繁体字・予約案内の追加デザイン。

掲載例の本文・数値・日付・店名を本番にコピーする資料ではありません。**実装は既存の全コンテンツを維持し、レイアウトとCSSを適用します。** 42種類の数はURL数や実装完了率とは別です。

## 同梱物

| ファイル | 用途 |
|---|---|
| index.html | 左右の比較と幅の切り替え |
| reference/ | 提出版v42のHTML・CSS・素材・利用条件 |
| target/ | 42種類＋6つの追加画面・状態の修正デザイン |

| evidence/ | 本番で測定した字級・見出し・幅の記録 |
| handoff/ | 原本v42から比較資料を再生成するためのソース |

## GitHubの設計ソースから再生成する場合

元の `ibatoco-all-pages-design-v42` フォルダを用意し、設計ソースのディレクトリで実行します。出力は元フォルダとは別にしてください。

```sh
python3 build_preview.py --reference /absolute/path/ibatoco-all-pages-design-v42 --output /absolute/path/new-v42-review
```

この処理はAstro・git・本番データを編集しません。原本はそのまま読み、別の出力先に資料を作ります。画像は既存素材を再利用しています。写真・挿絵・フォントの出典と利用条件は `reference/ARTWORK.md` と `reference/fonts/` を引き継いでいます。

## 検証の読み方

比較画面の「幅ごとのデザイン点検」は、320・375・390・768・1440pxで各デザインの横はみ出し・H1数・既存H1との対応・フォーム文字サイズを調べます。色や改行を含む見た目の最終確認、実サイトの機能・SEO・計測の検証を置き換えるものではありません。file://での表示では自動点検を行わず、画面比較を使えます。

資料作成時の本番測定はPC1440pxを32URL（検索状態の違いを含む33記録）、スマホ390pxを13ページで実施しました。TOPの比較、紅葉・多言語・予約案内は別途確認しています。診断結果やフォーム確認状態、公開データ0件の個別ページは、既存ソース・公開済みPRと設計例を区別して扱っています。未公開の店舗・書き手を実在の掲載ページとして数えていません。
