イバトコは、自分のサイトで使っている品質の検査を、1つのサイト向けに縮めて「サイト制作の型」に組み込みました。この記事の項目は、その型が公開前に自動で確かめている内容です（2026年11月26日時点）。受託先の事例ではありません。

## Googleが基本として挙げていること

- 検索に使われる言葉を、ページのtitleや見出しなど目立つ場所に置く（Google 検索の基本事項）
- ページごとに、内容を表す固有のtitleとmeta descriptionを付ける（ウェブ デベロッパー向けガイド）
- よいtitleは、そのページに固有で、簡潔で、内容を正確に表している（SEO スターター ガイド）

## 公開を止める項目（直さないと公開しない）

| 項目 | なぜ止めるか |
| --- | --- |
| `<html lang="ja">` がない | ページの言語が伝わらない |
| title がない | 検索結果の見出しをGoogleが別の場所から作ることになる |
| meta description がない | 検索結果の説明文を選ぶ手がかりが減る |
| canonical がない・https の絶対URLでない | 同じ内容のページがどれか伝わらない |
| OGP（og:title など）がない | SNSで共有したときに見出しや画像が出ない |
| h1 が1ページに1つでない | ページの主題がはっきりしない |
| 代替テキスト（alt）のない画像 | 画像の内容が伝わらず、読み上げにも困る |
| 構造化データが JSON として読めない | 書いたつもりの情報が伝わらない |
| ひな形の文字が残っている | 未完成のまま公開される |
| TOPに組織・店舗の構造化データがない | 運営者や店舗の情報が伝わらない |
| サイトマップ・robots.txt がない、全クローラーを拒否している | 検索に載らない |
| サイトマップとページが食い違う、リンク切れ | 存在しないページに誘導してしまう |

## 直したほうがよい項目（公開は止めない）

| 項目 | 目安 |
| --- | --- |
| title が長い | 全角60字を超えると検索結果で切れやすい |
| description が短い・長い | 50字未満・160字超を知らせる（70〜120字が目安） |
| 画像に width・height がない | 表示がずれる原因になる |
| パンくずの構造化データがない | サイト内の位置が伝わりにくい |
| llms.txt がない | AI向けにサイトの主なページをまとめた案内がない |
| title・description が他のページと同じ | 検索結果で区別がつかない |

## 観光・店舗のサイトで特に気をつけること

- **営業時間・料金・定休日は、ページの本文に文字で書く**：画像の中だけに書くと、検索にもAIにも読まれにくくなります
- **イベントは年と日付を書く**：「今年」「毎年」ではなく「2026年12月12日（土）」のように書きます
- **出典と更新日を出す**：変わりやすい情報には、確かめた日と公式の出典を添えます

## 自分の組織で試す手順

1. 公開予定のサイトのページを一覧にする
2. 上の「止める項目」を、1ページずつ確かめる（制作会社に自動チェックの有無を聞くのも有効です）
3. 公開後、Search Console にサイトマップを登録し、インデックスに載ったかを確かめる
4. 主な検索語で実際に検索し、titleと説明文がどう表示されているかを見る
